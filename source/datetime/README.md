# DateTime D/C++ Interop Library

Minimal sibling module to `json`, scaffolded with the same layout.

## Layout

- `source/datatime.d`: minimal D implementation
- `scripts/build.sh`: builds shared library and generated FFI header
- `build/generated/datetime_ffi.hpp`: generated by `ldc2`
- `build/include/datetime.hpp`: C++ wrapper (`DateTimeHandle`)
- `tests/main.cpp`: minimal usage sample
- `tests/build_and_run.sh`: build+run helper

## Build

```bash
./scripts/build.sh
```

## Test

```bash
./tests/build_and_run.sh
```
