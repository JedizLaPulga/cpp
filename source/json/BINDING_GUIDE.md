# D-to-C++ Binding Pattern for json module

## Architecture

This uses the **extern(C++) struct + extern(C) helper** pattern to work around D's C++ constructor/destructor limitations.

### Flow

1. **json.d** defines `extern(C++) struct Json` with data members and member functions
2. **ld2** generates `json.hpp` from the D struct definition
3. **Manually augment** `json.hpp` with inline constructor/destructor calling extern(C) helpers

## D Side (json.d)

```d
extern(C++) struct Json {
    JSONValue* data;
    
    void parse(const(char)* jsonStr) { ... }
    const(char)* stringify() { ... }
    long getLength() { ... }
}

extern(C) {
    void jsonInit(Json* obj) { ... }
    void jsonDestroy(Json* obj) { ... }
}
```

- `Json` struct: stores single `JSONValue* data` member, provides member functions
- Helper functions: `jsonInit()` and `jsonDestroy()` handle resource allocation/cleanup
- Member functions do actual work, keep them small and focused

## C++ Generated Header (json.hpp)

**After ld2 generates from json.d, manually add inline ctor/dtor:**

```cpp
// Generated by ld2:
extern "C" struct Json {
    JSONValue* data;
    
    void parse(const(char)* jsonStr);
    const(char)* stringify();
    long getLength();
};

// Manually add for C++ RAII:
extern "C" {
    void jsonInit(Json* obj);
    void jsonDestroy(Json* obj);
}

// Inline constructor/destructor wrapper
namespace json {
    struct JsonValue {
        Json _impl;
        
        JsonValue() { jsonInit(&_impl); }
        ~JsonValue() { jsonDestroy(&_impl); }
        
        void parse(const char* str) { _impl.parse(str); }
        const char* stringify() { return _impl.stringify(); }
        long getLength() { return _impl.getLength(); }
    };
}
```

## C++ Usage

```cpp
#include "json.hpp"

int main() {
    json::JsonValue obj;  // ctor calls jsonInit()
    obj.parse("{\"key\": \"value\"}");
    const char* result = obj.stringify();
    // dtor calls jsonDestroy() automatically
}
```

## Key Benefits

✅ **No C++ ctor/dtor issues** - D doesn't handle them, but extern(C) helpers do  
✅ **RAII works** - Inline ctor/dtor in .hpp provides automatic cleanup  
✅ **Minimal overhead** - Inline functions compile away  
✅ **Small focused features** - Each member function does one thing  
✅ **Clean struct definition** - D's type system visible in C++  

## Build Process

```bash
# 1. Compile D to object file
dmd -c json.d -fPIC -ofobj/json.o

# 2. Run ld2 to generate json.hpp
ld2 json.d -o json.hpp

# 3. Manually augment json.hpp with ctor/dtor (if not done by ld2)
# Edit json.hpp, add the inline constructor/destructor

# 4. Link as shared library
gcc obj/json.o -shared -lphobos2 -o libjson.so
```
